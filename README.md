# Libreria
Sistema de gestión y control desarrollado para la administración de una libreria y el control de su inventario. 

# Que hace el proyecto 
Este proyecto es un sistema de software diseñado para automatizar y centralizar la administración de una librería. Permite gestionar un catálogo de libros (con sus autores y categorías), llevar un control en tiempo real del stock disponible, registrar las ventas con sus respectivos detalles y tickets, y llevar un registro de ingresos y egresos de mercadería. Cuenta además con control de acceso por roles (Administrador y Vendedores).

# Por qué el proyecto es útil
Muchas librerías pequeñas llevan su inventario y sus ventas de forma manual en cuadernos o planillas sueltas, lo que suele provocar errores en las sumas, pérdida de control del stock y dificultad para calcular las ganancias reales. 
Este sistema es útil porque:
- Evita errores humanos en los cálculos y en el registro de ventas.
- Optimiza el tiempo de búsqueda de libros y emisión de comprobantes para los vendedores.
- Ofrece al administrador una visión clara del estado del negocio, el inventario y las finanzas.
